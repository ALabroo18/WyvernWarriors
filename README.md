# Wyvern Warriors

# Overview
Team: Fireborn Studios
Size: 14
Duration: Sep 2025 - Current

# About
Wyvern Warriors is a 3D flying action game. The Kingdom of Morningstar is attacked by an exiled prince and it is up to the Wyvern Warrior to save it. Explore through three levels, fighting enemies, and fufilling tasks to increase morality and defeat the main boss of the game, Maelstrom.
